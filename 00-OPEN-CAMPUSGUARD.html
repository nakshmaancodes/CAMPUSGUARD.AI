First time?

1. Double-click START-CAMPUSGUARD.bat in this folder.
2. Wait for the terminal to say the server is running.
3. Your browser will open CampusGuard automatically. You can also click “Open CampusGuard” above.

Keep this folder together. Add your API keys only to the empty .env file. Never paste keys into the website frontend.
